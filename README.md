# Internship Tracker Bot

A chatbot that helps students track their internship applications —
built as a college project, usable by classmates too.

## Problem it solves
Students applying to multiple internships lose track of deadlines,
statuses, and follow-ups across scattered notes, chats, and emails.
This bot lets you talk to it in plain English to log and check on
your applications.
